# Interface icon sources

`mail.svg` and `cv.svg` adapt the earlier Lucide Mail and File User icons. Their outlines have been redrawn to an inset keyline with 1.65-unit rounded strokes; the CV portrait detail has been replaced by two document lines. The original license is retained below.

`scholar.svg` is a geometric academic-cap pictogram authored for this interface, using the same grid and strokes. It is not the official Google Scholar logo. The adjacent text identifies the link destination.

Sources:
- https://github.com/lucide-icons/lucide/blob/main/icons/mail.svg
- https://github.com/lucide-icons/lucide/blob/main/icons/file-user.svg
