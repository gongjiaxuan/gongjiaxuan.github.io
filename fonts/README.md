# Local interface fonts

## Manrope (current portfolio interface)

`manrope-latin-variable.woff2` is the unmodified Latin variable WOFF2 from
`@fontsource-variable/manrope` version 5.3.0, retrieved 2 October 2026:
https://cdn.jsdelivr.net/npm/@fontsource-variable/manrope@5.3.0/files/manrope-latin-wght-normal.woff2

Copyright 2018 The Manrope Project Authors (https://github.com/googlefonts/manrope).
Licensed under the SIL Open Font License 1.1; see `Manrope-OFL.txt`.
The interface uses upright weights 400–700. Other scripts use system fallbacks.
The font is served locally; visitors do not request Google Fonts or a CDN.

## Archivo (retained from the earlier version)

Source: [Google Fonts / Archivo](https://github.com/google/fonts/tree/main/ofl/archivo), retrieved 30 September 2026.

Copyright 2020 The Archivo Project Authors. Licensed under the SIL Open Font License 1.1; see `Archivo-OFL.txt`.

`archivo-latin.woff2` is a local subset of the upright variable font, with width fixed at 100 and weight range 400-700. It contains Latin characters, common punctuation and arrows. Other scripts use the system-font fallback. No external font service is needed by the portfolio shell.

The independent CUT / PRINT editor retains its own original typography and font-loading behaviour.
